# План разработки Telegram-бота

## Описание проекта
Telegram-бот для пересылки сообщений между пользователями:
- Одно сообщение, один ответ
- Следующее сообщение идет другому получателю
- Без цепочек сообщений

## Архитектура системы

### Технологии
- **Backend**: Node.js с использованием Telegram Bot API
- **Frontend**: Telegram Bot (веб-интерфейс не требуется)
- **Хостинг**: Cloud-сервис (Heroku, Railway или VPS)
- **База данных**: SQLite (с абстракцией для легкого перехода на PostgreSQL)

### Основные компоненты
1. Telegram Bot API интеграция
2. Логика пересылки сообщений (одно сообщение - один ответ)
3. Механизм случайного выбора получателей
4. Хранение информации о пользователях и пересылках
5. Абстракция базы данных для легкого перехода на PostgreSQL
6. Многоязычность (текущая реализация на русском)

## Таски для разработки

### Таск 1: Настройка базовой структуры проекта
- Создание директории проекта
- Инициализация Node.js проекта
- Установка необходимых зависимостей (telegraf, dotenv, sqlite3)
- Создание основных файлов и структуры

### Таск 2: Интеграция с Telegram Bot API
- Получение токена бота от BotFather
- Настройка подключения к Telegram API
- Реализация базовой обработки сообщений

### Таск 3: Логика пересылки сообщений
- Реализация механизма случайного выбора получателя
- Создание логики "одно сообщение - один ответ"
- Обработка текстовых сообщений и медиа

### Таск 4: Управление пользователями с SQLite
- Создание схемы базы данных для пользователей
- Реализация CRUD операций для пользователей
- Интеграция с Telegram API для регистрации пользователей

### Таск 5: Хранение информации о пересылках
- Создание схемы базы данных для пересылок
- Логика отслеживания отправки и получения сообщений
- Абстракция базы данных для легкого перехода на PostgreSQL

### Таск 6: Обработка ответов
- Пересылка ответов обратно отправителю
- Обработка команд (например, /start, /help)
- Управление состоянием пользователей

### Таск 7: Локализация и текстовые сообщения
- Вынесение всех текстовых сообщений в отдельные файлы
- Поддержка многоязычности
- Упрощение добавления новых языков

### Таск 8: Тестирование и отладка
- Проверка работы всех компонентов
- Тестирование логики пересылки
- Отладка возможных ошибок

### Таск 9: Развертывание
- Подготовка к хостингу
- Настройка переменных окружения
- Деплой на выбранную платформу

│   │   ├── db.js             # Абстракция базы данных
